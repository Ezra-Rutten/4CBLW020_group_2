# Birmingham station folder

This folder contains the police-station input for the dashboard.

Files:
- `stations.json`: station data used by the website
- `police_stations.csv`: the same station data in CSV format
- `summary.json`: city metadata and, for London, the EDA monthly crime input

The station names come from the group `backend/services/police_shape.py` list. Coordinates are included so the dashboard map can place the stations visually.
